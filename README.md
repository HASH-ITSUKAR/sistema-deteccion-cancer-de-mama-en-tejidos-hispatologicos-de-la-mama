## 🇪🇸 Descripción del Proyecto
Este sistema es una solución integral para la **detección de cáncer de mama en tejidos histológicos**. Utiliza modelos de *Deep Learning* para analizar imágenes de 50x50 píxeles.

### 📥 Configuración
1. **Recursos:** Descarga el [Drive del Proyecto](https://drive.google.com/drive/folders/1aNT_6z5iHrFOSZCK5WoSKxxA5V0enuCb?usp=drive_link).
2. **Estructura de Carpetas:**
   - Modelos: `histologico_backend/modelo/scripts/modelos/`
   - Fonts: `histologico_frontend/public/assets/fonts/`

### ⚙️ Funcionamiento
1. **Entrada:** El usuario sube una imagen de 50x50 px.
2. **Proceso:** El backend aplica los modelos pre-entrenados.
3. **Resultado:** El sistema devuelve el diagnóstico.
